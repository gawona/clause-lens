# ClauseLens 🔍✨

계약서·약관·정책 문서의 핵심 항목 추출, 근거 기반 질의응답, 위험 조항 탐지를 제공하는 RAG 기반 AI 문서 분석 플랫폼입니다.

## 주요 기능

- PDF 문서 업로드
- PDF 텍스트 추출
- 문서 chunking
- OpenSearch 기반 검색
- RAG 기반 질의응답
- 근거 문장 및 페이지 표시
- 핵심 항목 JSON 추출
- 위험 조항 탐지
